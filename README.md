# PRTS 个人工作台

以《明日方舟》PRTS 的视觉语言为灵感，整理待办、笔记、文件与专注时间的个人工作台。前端使用 React、TypeScript 和 Vite，后端使用 Node.js 原生 HTTP 服务，可选接入 OpenAI 兼容的 AI 服务。

界面包含启动序列、菜单切换、弹窗和几何扫描等网页动效。它们是本项目的实现，未针对指定游戏版本逐帧校准，不承诺与原版完全一致。

## 功能

- **终端总览**：阿米娅原始游戏立绘，查看任务、最近笔记、操作动态和专注计时。素材来源与权利说明见 [图片素材记录](docs/assets.md)。
- **密码入口**：进入任何模块前验证密码，支持刷新保留会话和主动锁定，后端接口同步验证登录。
- **任务管理**：自定义分类，按分类分栏；总栏桌面每行三列，窄屏自动缩为两列或一列。支持栏内新增、编辑时换分类、完成和删除任务，以及优先级、截止日期、搜索和筛选。
- **笔记档案**：Markdown 编辑与预览、自动保存、标签、置顶和搜索。
- **文件资料**：选择或拖入文件，搜索、筛选、图片预览、下载和删除。
- **PRTS 助手**：本地规则指令、三种性格的 AI 对话，以及《明日方舟》和《明日方舟：终末地》语料检索与来源引用。
- **系统设置**：昵称、专注时长、完成提示音、动效开关、语料首次下载与更新，以及 JSON 备份导入导出。

首次使用包含示例任务和笔记；文件库初始为空。

任务分类可在「任务中枢 → 管理分类」中新增、改名或删除。分类最多 50 个，名称最多 40 字；删除分类会把任务移入「未分类」，不会删除任务。旧版任务也会保留在「未分类」，可通过编辑任务选择分类；新建示例工作台包含工作、学习、生活三个分类。分类信息随工作台 JSON 备份一并保存，旧备份可导入并自动迁移。

AI 性格、参考语料、检索作品及任务优先级使用统一的 PRTS 深色下拉面板，支持方向键、Home/End、Enter/空格选择、Esc 关闭与 Tab 离开；在手机和任务弹窗中也可使用。

## 本地开发

需要 **Node.js 22.18.0 或更高版本**及 npm。

```sh
npm install
```

首次使用时复制 `.env.example` 为 `.env`，填写 `PRTS_PASSWORD`。已有 `.env` 时直接补充该变量，避免覆盖原配置。然后启动：

```sh
npm run dev
```

打开 <http://127.0.0.1:5173>。该命令同时启动 Vite 前端和 `127.0.0.1:8787` 的 API 服务，前端将 `/api` 请求代理给后端。

访问密码是必填项。登录后，不配置 AI API 密钥也可以使用任务、笔记、文件、专注计时、助手的本地指令和已同步语料的离线检索。例如：

```text
今日任务
查看笔记
搜索笔记 工作
新建任务：整理本周笔记
专注状态
```

本地指令按固定规则执行，不调用模型。

## 访问密码

密码由服务端 `.env` 中的 `PRTS_PASSWORD` 设置，前端不会保存密码或自行判断密码是否正确。未配置、空白或超过 1024 字节的密码会使服务保持锁定。

```dotenv
PRTS_PASSWORD=填写独立的长随机密码
PRTS_COOKIE_SECURE=false
```

修改密码后重启服务。已有会话也会随服务重启失效。登录会话固定有效 12 小时；刷新页面可以继续使用，点击右上角「锁定终端」会撤销当前会话并回到密码入口。密码错误会显示提示；同一来源 10 分钟内达到 5 次失败后暂时限制尝试。

工作台仅在服务端验证成功后挂载，直接访问笔记等深链接仍会先显示登录页。所有工作台 API（包括 AI 服务）都验证会话。前端在接口返回未登录、会话到期、重新切回窗口或定期检查时重新锁定；网络不可用时也不会放行。退出失败时保留锁定状态，重新连接会先完成服务器退出。

会话使用 `HttpOnly`、`SameSite=Strict` Cookie；HTTPS 部署时设置 `PRTS_COOKIE_SECURE=true`，并由反向代理保留原始 Host。相关属性含义见 [MDN Set-Cookie 文档](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie)。默认开发环境仅监听本机 HTTP。

密码入口控制界面和服务端 API 的访问。任务、笔记和文件仍保存在当前浏览器中，没有对浏览器磁盘存储进行加密；锁定不会删除已有数据。

## 配置 AI 服务

```sh
# 已存在 .env 时直接编辑；首次配置才需要复制。
cp -n .env.example .env
```

编辑项目根目录的 `.env`：

```dotenv
OPENAI_API_KEY=填写你的服务密钥
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4.1-mini
HOST=127.0.0.1
PORT=8787
```

也可以将 `OPENAI_BASE_URL` 和 `OPENAI_MODEL` 改为兼容服务的 API 根地址和模型名称。后端使用非流式 Chat Completions 接口，请确认服务支持 `/chat/completions`。

保存后重启服务，在助手中切换到「AI 对话」。启动脚本通过 Node.js 的 `--env-file-if-exists=.env` 读取配置，密钥只由服务端使用；不要把密钥写入 `VITE_` 环境变量或前端代码。

没有密钥时，AI 接口会返回明确的未配置提示，本地指令仍然可用。页面上的配置状态只表示后端已读取到配置，不代表已经成功连接模型。**当前已验证模拟上游的成功、错误和超时处理，尚未使用真实服务密钥实测 AI 对话。**

在「AI 对话」中可选择 **PRTS（理性分析）**、**阿米娅（温和鼓励）**或**凯尔希（严谨直言）**。性格与参考语料范围保存在当前浏览器的 `localStorage`，刷新后保留，对后续回复生效；它们是角色风格预设，不代表官方角色身份。

助手当前页签保存在本标签页的 `sessionStorage`，刷新后仍停留在原来的本地指令、AI 对话或语料检索页签。历史 AI 回复保留生成时的性格与引用来源。

AI 请求包含当前 AI 对话上下文、所选性格指令，以及按参考范围检索到的相关语料片段。可选择两部作品、仅一部作品或关闭资料检索；回复附带可展开的来源、原文片段和行号。相关片段会随请求发送到所配置的模型服务，不会自动附带待办、个人笔记、文件或本地指令历史。助手不会加载回复中的 Markdown 图片。请求失败或取消后，输入会保留以便重试。

## 本地语料与同步

当前工作目录已内置两个语料库，共 **34,007 篇文档**。登录后，在「PRTS 助手 → 语料检索」中可按关键词和作品检索原文。检索由本地 Node.js 后端读取本地资源完成，资源就绪后无需外网或 AI 密钥；AI 生成仍需要上节的模型配置。

检索结果与 AI 引用中的原文支持 Markdown 标题、列表、强调、引用和代码排版。语料中的游戏图片标记通过独立的本地图片清单匹配原图，支持正文配图、社交图片和行内表情/图标；图片可点击查看原图，涉及男女管理员的图片提供版本切换。代码示例中的字面标记保持原样，未匹配资源仍显示「原文配图未收录」。原文不会自动加载任意远程图片或执行 HTML。

当前补充图片共 **185 张原始 PNG**，覆盖当前语料全部 119 个正文图片标记，以及 63 个社交图片、表情和图标标记；还有 2 个社交图片 ID 暂未找到可确认的原图。图片保存在 `public/assets/corpus-images/`，构建时复制到 `dist`，来源和校验清单见 [图片素材记录](docs/assets.md)。需要恢复或校验这批图片时运行 `node scripts/sync-corpus-images.mjs`，将按固定版本逐张核验并复用已有文件；重新生成图片清单后再构建。该命令维护已确认的图片映射；语料更新后新增的未知图片标记需要补充映射，不能按近似文件名自动配图。

| 语料库           | 当前文档数 | 原始下载渠道                                                                                                                    |
| ---------------- | ---------: | ------------------------------------------------------------------------------------------------------------------------------- |
| 明日方舟         |     17,801 | [ModelScope：HTiantian/prts-agent-corpus-arknights](https://modelscope.cn/datasets/HTiantian/prts-agent-corpus-arknights/files) |
| 明日方舟：终末地 |     16,206 | [ModelScope：HTiantian/prts-agent-corpus-endfield](https://modelscope.cn/datasets/HTiantian/prts-agent-corpus-endfield/files)   |

当前已同步版本为 `agent-corpus-v2-20261018-endfield-1.6.3-release-v3`。该版本包含 7 个分区、1,590 个 gzip 资源，压缩资源合计 259,762,666 字节；连同分区清单共核验 1,597 个文件。版本和来源依据见 [语料来源说明](data/corpus/SOURCES.md)、[当前版本](data/corpus/current.json)及对应版本目录中的 `sync-report.json`。

**Git 不包含原始 `.gz` 资源。新检出项目后，可在「系统设置 → 语料管理」中完成首次下载。** 同步需要服务端安装 **Node.js 22.18.0 或更高版本和 `curl`**，首次下载约 **260 MB**。

- 没有本地语料时，点击「首次下载语料」；已有语料时，点击「检查并更新语料」。
- 页面显示检查、下载、校验和启用阶段，以及可用的文件数与字节进度。同步由后端执行，离开设置页或刷新浏览器后仍会继续；返回设置页会恢复任务状态。
- 已校验的本地文件会复用，缺失或损坏的文件才重新下载。更新成功后自动切换至新版本，**通过界面更新无需重启后端**；已经是最新版本时会显示校验完成。
- 更新失败时保留原有可用语料，页面显示错误并允许重试；再次同步会复用已经完成的文件。

也可以通过命令行预先同步或维护语料：

```sh
node scripts/sync-corpus.mjs
```

命令行默认并发为 10，可使用 `node scripts/sync-corpus.mjs --concurrency 8` 调整。脚本通过 PRTS 已批准发布清单确定版本，从 ModelScope 下载原始资源，逐文件核对大小和 SHA-256；再次运行仅补齐缺失或损坏文件，全部通过后才更新 `data/corpus/current.json`。**命令行同步完成后，需重启已经运行的后端以读取新版本**；尚未启动服务时，正常启动即可。

清单与资源保存在 `data/corpus/releases/<release>/`，包括原文、文档目录、检索索引和终末地本地化资源。缺少语料时界面会提示尚未就绪。两份上游数据集均声明 `license: other`，游戏内容及其他资料的权利归各自原权利人；完整说明见 [语料来源说明](data/corpus/SOURCES.md)及随版本保存的上游 README。

## 生产运行

```sh
npm run build
npm start
```

打开 <http://127.0.0.1:8787>。同一个 Node.js 服务提供 `dist` 中的静态页面和 `/api` 接口，默认仅监听本机。可以通过 `.env` 中的 `HOST`、`PORT` 调整监听地址和端口。若修改开发环境的 API 端口，也需同步修改 `vite.config.ts` 的代理目标。

生产语料检索还需要完整的 **`data/corpus` 原始资源**：部署时保留 `current.json`、对应版本的清单和全部 gzip 文件，或启动后在「系统设置 → 语料管理」下载，也可在目标机器运行同步命令。界面下载的文件保存在后端所在机器。`npm run build` 只构建前端，不会把语料打包进 `dist`；仅复制构建产物或 Git 仓库不足以提供离线检索。

## 数据与备份

数据保存在当前浏览器中，使用一个工作台访问密码，没有多用户账号或云同步。

| 数据                                         | 保存位置                         | JSON 备份 |
| -------------------------------------------- | -------------------------------- | --------- |
| 任务、笔记、操作动态、系统设置、累计专注次数 | `localStorage`                   | 包含      |
| 当前专注计时状态、动效偏好                   | `localStorage`                   | 不包含    |
| 助手性格与参考语料范围                       | `localStorage`                   | 不包含    |
| 文件内容与文件信息                           | `IndexedDB`                      | 不包含    |
| 最近 60 条已完成的助手消息                   | `sessionStorage`，当前标签页会话 | 不包含    |

文件限制为**单个 20 MB、总计 100 MB**，按 `1024 × 1024` 字节计算，实际可用空间还受浏览器存储配额限制。文件不会自动上传到服务器。

公共游戏语料保存在服务端的 `data/corpus`，不属于浏览器工作台数据，也不包含在 JSON 备份中。

在「系统设置」中导出 JSON 备份。导入时会检查格式，并在确认后替换当前工作台数据；导入文件最大为 10 MB。**JSON 不包含文件和聊天记录**，需要保留的文件请单独下载。导入 JSON 不会替换文件库或聊天记录。

浏览器清理站点数据、更换浏览器或使用不同地址都会影响数据可见性。开发地址 `127.0.0.1:5173` 与生产地址 `127.0.0.1:8787` 使用独立存储，可通过 JSON 备份迁移其中包含的数据。

## 快捷键与动效

| 操作                               | 快捷键           |
| ---------------------------------- | ---------------- |
| 打开全局搜索                       | `⌘ K` / `Ctrl K` |
| 选择搜索结果                       | `↑` / `↓`        |
| 打开选中的搜索结果                 | `Enter`          |
| 发送助手消息                       | `Enter`          |
| 助手输入换行                       | `Shift Enter`    |

## 验证

运行单元测试、后端接口测试和生产构建：

```sh
npm test
npm run build
```

测试覆盖工作台数据校验、助手上下文与本地指令、文件容量计算、API 参数与错误处理，以及静态资源路径安全等。后端上游使用模拟服务，不需要真实 API 密钥。

设置页语料首次下载、更新、进度恢复与免重启切换的本轮验收状态记录于 [验证记录](docs/qa.md)。阿米娅立绘、性格偏好、检索与引用等历史通过结果不代表本次变更已经完成回归。

端到端测试使用系统安装的 **Microsoft Edge**（`channel: 'msedge'`），以 **`headless: false`** 打开可见窗口，因此需要桌面环境。**无需安装 Playwright 的 Chromium**。

先在一个终端启动开发服务。浏览器用例模拟 AI 配置状态，不会修改或调用你当前配置的模型服务：

```sh
npm run dev
```

再在另一个终端运行：

```sh
npm run test:e2e
```

端到端测试读取 `.env` 或环境变量中的 `PRTS_PASSWORD`，通过真实登录建立会话。它覆盖密码入口、锁定、未登录深链接和接口拦截，以及任务、笔记、文件持久化、搜索、助手、专注计时、备份、响应式布局、启动动效和数据恢复。AI 成功与重试场景使用拦截的模拟响应，不调用真实模型。为避免记录密码和会话令牌，测试关闭了 trace；结果目录为 `/tmp/prts-playwright-results`。

检查代码和文档格式：

```sh
npm run format:check
```
